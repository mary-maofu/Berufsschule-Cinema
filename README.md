# Berufsschule-Cinema
# 🎬 Film- und Schauspieler-Datenbank

## 📌 Projektbeschreibung
Dieses Projekt ist im Rahmen des Unterrichts an der Berufsschule entstanden.  
Ziel des Projekts ist es, eine Datenbank zu erstellen, in der Filme sowie deren Schauspieler gespeichert und verwaltet werden können.

Die Datenbank enthält unter anderem Informationen zu:
- Filmen
- Schauspielern (Actor)
- Beziehungen zwischen Filmen und Schauspielern
- weiteren relevanten Daten (z. B. Erscheinungsjahr, Genre, Rollen, etc.)

Die Datenbank wurde mit **MySQL** erstellt und über **phpMyAdmin** verwaltet.

---

## 🛠️ Verwendete Technologien
- MySQL
- phpMyAdmin
- SQL
- JS
- HTML
- SCSS

---

## 🗄️ Datenbankstruktur (Beispiel)
Die Datenbank besteht aus mehreren Tabellen, zum Beispiel:

- **movies**
  - id
  - titel
  - erscheinungsjahr
  - genre
  - dauer

- **actors**
  - id
  - vorname
  - nachname
  - geburtsdatum
  - nationalität

- **movie_actor**
  - movie_id
  - actor_id
  - rolle

Diese Struktur ermöglicht es, mehrere Schauspieler einem Film zuzuordnen.

---

## 🎯 Ziel des Projekts
- Verständnis für relationale Datenbanken
- Arbeiten mit SQL-Abfragen
- Nutzung von phpMyAdmin
- Modellierung von Beziehungen zwischen Tabellen
